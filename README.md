# Suraj-steel-website-

Official industrial web application for **Suraj Pipe And Fitting** — Precision Manufacturer & Stockist of Forged Fittings, Flanges, Buttweld Fittings, Fasteners, Pipes & Tubes, Sheets & Plates, and Rods & Bars.

## Technologies Used
- React 18
- Vite
- React Router DOM
- Lucide React
- Modern CSS3 with Responsive Architecture

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
